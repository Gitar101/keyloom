# Keyloom v0.1.1

Branding update for the Windows app. Lighting behavior and supported device
commands are unchanged.

- Original pixel-art Keyloom icon for the executable and native app windows.
- Matching SVG, PNG, multi-resolution Windows icon, and favicon in `assets/`.
- Reproducible icon generation and automated pixel/packaging asset checks.
- Build story, X launch copy, and an edited cover using the actual UI and a
  supplied Apex100 product photo. Blog images are not bundled into the app.

Download `Keyloom-windows-x64.exe`. `SHA256SUMS.txt` records its SHA-256 hash.
The executable is unsigned; do not disable Windows security to run it.

Experimental: tested with one wired Apex100/GZS68. Close the original Apex100
tray app and other RGB tools before syncing. No key mappings, persistent
profiles, resets, or firmware are written. See the README for capture,
compatibility, and privacy limitations.
