# Keyloom v0.1.0

Initial public release for Windows x64 and the wired Ant Esports Apex100/GZS68.

- 68 spatial screen regions mapped through the keyboard's factory matrix.
- Independent smooth per-key transitions and brightness control.
- Adjustable black cutoff: near-black regions fade their keys fully off; default 16/255.
- Native desktop preview, Start/Stop, and preview-only mode.
- Continuous RGB delivery, including static pictures.
- Standalone executable with no Python installation or administrator access required.

Download `Keyloom-windows-x64.exe`. `SHA256SUMS.txt` records its SHA-256 hash. The executable is unsigned. Source code is included in the repository and GitHub's source archives.

Experimental: one wired model/layout has been tested. Close the original Apex100 tray application and other RGB software before syncing. Wireless modes and other keyboards are unsupported. No key mappings, persistent profiles, resets, or firmware are written. See the README for capture/firmware limitations and privacy details.
