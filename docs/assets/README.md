# Launch artwork

`keyloom-cover.png` is the public blog and social cover. It combines a
user-supplied Ant Esports Apex100 promotional keyboard photograph, a supplied
Keyloom UI screenshot, and Keyloom's original pixel icon through an AI-assisted
image edit. Any exact screenshot replacement and final sizing are local
compositing steps.

The product photograph and manufacturer marks retain their respective owners'
rights and are not relicensed under the repository's MIT code license. The
Keyloom icon is original project artwork under MIT. No affiliation or
endorsement by Ant Esports is implied.

The cover is edited artwork, not evidence that a particular frame or lighting
effect was displayed on the physical keyboard. The original uploads and their
metadata are not included in the repository or executable. The cover itself
is not bundled into the application.
